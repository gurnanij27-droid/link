# Navigation Bar using HTML and CSS
About the Project

This project is a simple and attractive navigation bar created using HTML and CSS. It contains different menu items to navigate between website pages.

# Technologies Used
HTML5
CSS3
# Features
Simple navigation bar design
Orange and yellow gradient background
Lavender blush navigation box
Home, About Us, Gallery, Project, and Achievement links
Flexbox for alignment
Rounded corners and styled links
Pages Included
Home
About Us
Gallery
Project
Achievement
# How to Run
Save the code in a file named index.html.
Keep the linked HTML pages in the same project folder.
Open index.html in any web browser.
Click the menu links to navigate between pages.
